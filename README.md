# PinBuilds extension for Gemini CLI

Create Pinterest pins from a blog post or a Shopify, WooCommerce or Etsy product, and schedule them to your Pinterest boards, from Gemini CLI.

The extension connects Gemini CLI to the PinBuilds remote MCP server (`https://pinbuilds.com/api/mcp`). Gemini CLI starts the PinBuilds sign-in (OAuth) the first time you use a tool.

## Install

```
gemini extensions install https://github.com/abdul712/gemini-cli-pinbuilds
```

## Example prompts

- "Make 3 Pinterest pins for https://myblog.com/easy-lasagna and schedule them to my Dinner board."
- "How many PinBuilds pins do I have left this month?"

## Requirements

A PinBuilds account (7-day free trial) and, for scheduling, a connected Pinterest account.
